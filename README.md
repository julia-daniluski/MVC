# MVC
 
## O que é MVC?

* M: Model
* V: View
* C: Controler

É um padrão de arquitetura, usado para organizar o código de forma clara, separando a lógica em 3 partes.

## Esquema MVC

usuários(navegador) -> Requisição -> controler -> model -> controler -> view -> usuarios.
